# Agentic AI with LangGraph

## 📚 Overview

This module covers **agentic AI patterns** using LangGraph. Learn to build autonomous agents that can reason, plan, and take actions.

---

## 🎯 Learning Objectives

By completing this module, you will be able to:

- ✅ Understand **agent architectures** and patterns
- ✅ Build agents with **LangGraph**
- ✅ Implement **Agentic RAG** for enhanced retrieval
- ✅ Design **multi-step reasoning** workflows
