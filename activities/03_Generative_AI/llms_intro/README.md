# Introduction to LLMs

## 📚 Overview

This module introduces **Large Language Models (LLMs)** and their APIs. Learn to interact with LLMs using OpenAI, Ollama, AWS Bedrock, and understand core concepts like embeddings and agents.

---

## 🎯 Learning Objectives

By completing this module, you will be able to:

- ✅ Use **OpenAI API** for text generation
- ✅ Run local LLMs with **Ollama**
- ✅ Access AWS **Bedrock** for enterprise models
- ✅ Understand **embeddings** for semantic search
- ✅ Implement basic **ReAct agents**
