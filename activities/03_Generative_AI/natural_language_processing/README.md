# Natural Language Processing (NLP)

This module covers **foundational NLP** concepts including text preprocessing, tokenization, and transformer architectures (BERT, GPT).

By completing this module, you will be able to:

- ✅ Apply **BERT** for NLP tasks
- ✅ Understand **GPT architecture** fundamentals
