## 📚 Overview

## 🔍 Methods Covered

| Method | Description | Use Case |
|--------|-------------|----------|
| **MMM** | Regression-based channel impact | Budget allocation |
| **First-Touch** | Credit first interaction | Awareness campaigns |
| **Last-Touch** | Credit final interaction | Conversion focus |
| **Linear** | Equal credit all touchpoints | Balanced view |
| **Time-Decay** | Recent touchpoints weighted higher | Recent impact focus |
