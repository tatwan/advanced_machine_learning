# Feature Engineering & Preprocessing Pipelines

## 📚 Overview

This module covers **advanced feature engineering** and **preprocessing techniques** using scikit-learn pipelines and feature-engine. Learn to build robust, reproducible data transformation workflows.

---

## 🎯 Learning Objectives

By completing this module, you will be able to:

- ✅ Build **scikit-learn preprocessing pipelines**
- ✅ Apply **advanced feature engineering** techniques
- ✅ Implement **denoising techniques** for cleaner data
- ✅ Use **feature-engine** for specialized transformations
- ✅ Chain multiple transformations in reproducible workflows
