# MLOps Demos: MLflow & Weights & Biases (WandB)

This directory contains **beginner-friendly, hands-on** notebooks for teaching MLOps concepts using two industry-standard tools: **MLflow** (open-source, self-hosted) and **Weights & Biases** (managed, cloud-based).

## 📂 Available Demos

| Tool | Notebook File | Description |
|------|--------------|-------------|
| **MLflow** | `mlflow_demo.ipynb` | Complete guide to local experiment tracking, model registry, and serving. |
| **WandB** | `wandb_demo.ipynb` | Guide to cloud-based tracking, visualization, and artifact management. |

---

## 📚 Learning Objectives

By completing these notebooks, you will learn to:

1. **Experiment Tracking** - Log parameters, metrics, and models systematically
2. **Autologging** - Automatically capture ML metadata with minimal code
3. **Model Registry & Versioning** - Manage model lifecycle (Staging → Production)
4. **Hyperparameter Tuning** - Compare multiple runs with nested experiments
5. **Artifact Logging** - Save plots, confusion matrices, and data files
6. **Model Loading** - Retrieve and use previously trained models
7. **Querying Experiments** - Programmatically search and filter runs
8. **Model Serving** - Deploy models for predictions (advanced topic)
9. **Best Practices** - Industry-standard MLOps workflows

## 🛠️ Prerequisites & Installation

**It is highly recommended to run these commands in a new virtual environment** to avoid conflicts.

### 1. Create a Virtual Environment

```bash
# Create a new virtual environment
uv venv dev1 --python=3.12

# Activate it (macOS/Linux)
source dev1/bin/activate

# Or activate it (Windows)
dev1\Scripts\activate
```

### 2. Install Required Packages

Install the required packages for both demos:

```bash
# Using uv (faster)
uv pip install mlflow wandb scikit-learn matplotlib pandas

# Or using pip
pip install mlflow wandb scikit-learn matplotlib pandas
```

## 🚀 Running the MLflow Demo

### Quick Start

1. **Open `mlflow_demo.ipynb`** in VS Code or Jupyter.

2. **Start the MLflow UI** (in a terminal in the notebook's directory):
   ```bash
   mlflow ui
   ```

3. **Open the MLflow UI** in your browser at: **`http://127.0.0.1:5000`**
   - ⚠️ Use `127.0.0.1` NOT `localhost` (newer MLflow security requirements)

4. **Run the notebook cells sequentially** and refresh the MLflow UI to see results.

## 🪄 Running the WandB Demo

### Quick Start

1. **Sign Up**: Go to [wandb.ai](https://wandb.ai/site) and create a free account.
2. **Get API Key**: Copy your key from [Settings/API Keys](https://wandb.ai/settings).
3. **Open `wandb_demo.ipynb`** in VS Code or Jupyter.
4. **Run the notebook**: The first time you run `wandb.login()`, paste your API key when prompted.

### Key Features to Explore
- **Dashboard**: Click the link generated by `wandb.init()` to see live charts.
- **System Metrics**: WandB automatically tracks GPU/CPU usage.
- **Reports**: You can create shareable reports directly in the dashboard.

## ❓ Troubleshooting

### MLflow Issues
- **Blank screen on UI**: Use `http://127.0.0.1:5000` instead of `http://localhost:5000`.
- **"pyenv binary not found"**: Add `--env-manager=local` flag when serving models.
- **Cannot find runs**: Ensure `mlflow ui` is running in the same directory as the `mlruns` folder.

### WandB Issues
- **Login fails**: Run `!wandb login --relogin` in a cell to enter a new key.
- **Offline mode**: If you have no internet, set `os.environ["WANDB_MODE"] = "offline"`.

### General
- **Large repository size**: Add `mlruns/` and `wandb/` to your `.gitignore` file to avoid committing experiment data.

**Example `.gitignore`:**
```
mlruns/
wandb/
*.pyc
__pycache__/
.venv/
```
