# Autoencoders

## 📚 Overview

This module covers **autoencoders** for dimensionality reduction, feature learning, and data reconstruction. Learn to build neural networks that learn efficient representations of data.

---

## 🎯 Learning Objectives

By completing this module, you will be able to:

- ✅ Understand **autoencoder architecture** (encoder-decoder)
- ✅ Build **basic autoencoders** for dimensionality reduction
- ✅ Implement **denoising autoencoders** for noise removal
- ✅ Apply autoencoders to **anomaly detection**
- ✅ Use learned representations for downstream tasks
